# ScreenCap

常駐在系統匣的 Windows 截圖工具，用 .NET 10 WPF 寫成。可以截圖並加上標註、把圖片貼在桌面上、錄成 GIF 或 MP4，以及辨識圖片中的文字。

## 功能

**截圖**
- 框選任意範圍，滑鼠移過時自動偵測視窗與控制項
- 放大鏡顯示游標座標與 HEX / RGB 色值，按 `C` 複製色值，按 `Shift` 切換複製的格式
- 方向鍵逐像素微調選取範圍；`Ctrl+A` 選取整個螢幕
- 按 `,` / `.` 切換到之前截過的範圍
- 延遲截圖（3 / 5 / 10 秒），方便截下拉選單或滑鼠提示
- 可選擇把滑鼠游標也截進去

**標註**
- 矩形、橢圓、箭頭、直線、畫筆、螢光筆、序號標記、文字（可設粗體、底色）、馬賽克或高斯模糊（可調強度）
- 矩形與橢圓可以填滿；線條可以改成虛線；標註可以調不透明度
- 按住 `Shift` 畫正方形、正圓、45° 箭頭與直線
- 畫好的標註在完成截圖前都能再選取、移動、調整大小、改顏色
- 14 種預設顏色，另有調色盤可用色塊或 HEX 色碼自訂，並記住最近用過的顏色；也能用吸管從截圖上取色
- 可以復原 / 重做

**輸出**
- 複製到剪貼簿、另存 PNG / JPG / BMP
- `Ctrl+Shift+S` 快速存檔：不跳對話框，直接存到設定的資料夾
- 自訂檔名格式：日期、時間、視窗標題、流水號，例如 `{title}_{n}`

**貼圖**
- 把截圖或剪貼簿中的圖片固定在所有視窗最上層
- 剪貼簿是文字時貼成便條；是色碼（`#1E88E5`、`rgb(30, 136, 229)`）時貼成色塊
- 滾輪縮放、`Ctrl+滾輪` 調透明度、旋轉與翻轉
- 可以回到編輯器再加標註
- 滑鼠穿透：點擊會穿過貼圖，點到後面的視窗

**錄影**
- 錄下任意範圍，滑鼠游標也會錄進去
- 可以暫停 / 繼續，暫停的時間不會出現在影片中
- GIF：每秒 10 格，只編碼有變化的部分，畫面靜止時檔案很小
- MP4：每秒 30 格，使用 Windows 內建的 H.264 編碼器
- 錄影範圍的紅框和控制列不會被錄進去，控制列可以拖曳移開；存檔後檔案會同時複製到剪貼簿

**長截圖**
- 自動用滑鼠滾輪往下捲動，並把每一段拼接成一張長圖
- 網頁頂端或底部固定不動的區塊只保留一份；選取範圍內含捲軸或側邊欄也能對齊
- 完成後可以預覽、複製、另存或做文字辨識

**文字辨識（OCR）**
- 使用 Windows 內建的辨識引擎，不需要連網
- 支援中英文混合；中文字之間不會多出空格
- 辨識結果可以修改後再複製

**其他**
- 淺色 / 深色模式，可設為跟隨 Windows
- 熱鍵、存檔資料夾、開機時啟動都可以在設定中調整
- app 內附使用說明

## 預設熱鍵

| 熱鍵 | 功能 |
|---|---|
| `F1` | 截圖 |
| `Shift+F1` | 錄影；錄影中再按一次停止 |
| `F3` | 把剪貼簿中的圖片（或文字、色碼）貼到桌面 |

熱鍵可以在系統匣選單的「設定」中更改。截圖畫面與貼圖上的其他快捷鍵，請看系統匣選單裡的「使用說明」。

## 系統需求

- Windows 10 2004（組建 19041）或更新版本，建議 Windows 11
- 執行：[.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
- 建置：.NET 10 SDK
- 文字辨識需要 Windows 已安裝對應語言的 OCR 元件：到「設定 → 時間與語言 → 語言與地區」新增語言，例如中文（台灣）

## 建置與執行

```powershell
# 建置並執行
dotnet run --project src/ScreenCap

# 執行測試
dotnet test

# 發佈到 publish 資料夾（需要目標電腦有安裝 .NET 10 Desktop Runtime）
dotnet publish src/ScreenCap -c Release -r win-x64 --self-contained false -o publish
```

啟動後只會出現系統匣圖示。ScreenCap 同一時間只會執行一份，重複開啟時新的會直接結束。

> ScreenCap 執行時會鎖住 `bin` 裡的執行檔，所以重新建置前要先從系統匣結束它。如果不想關掉，可以加 `--artifacts-path <其他資料夾>`，把建置輸出放到別處。

## 專案結構

```
src/ScreenCap/
  Annotations/   標註模型、復原堆疊、把標註合成進截圖
  Capture/       截圖畫面（選取、放大鏡）、工具列、調色盤
  Help/          app 內的使用說明
  Native/        Win32 P/Invoke
  Ocr/           文字辨識結果視窗
  Pin/           貼圖視窗
  Recording/     錄影流程、GIF 編碼器、MP4（Media Foundation）編碼器、錄影控制列
  Scrolling/     長截圖：自動捲動、拼接演算法、結果視窗
  Services/      擷取螢幕、偵測視窗、熱鍵、剪貼簿、存檔、設定、OCR
  Settings/      設定視窗
  Theme/         淺色 / 深色配色與控制項樣式
  Tray/          系統匣圖示與選單
tests/ScreenCap.Tests/  xUnit 測試
```

## 實作說明

- **座標與 DPI**：截圖一律以實體像素處理，並以 Per-Monitor V2 DPI 感知執行，在高縮放比例下也不會模糊或偏移。
- **截圖**：用 GDI `BitBlt` 一次擷取整個虛擬螢幕（所有螢幕合起來的範圍），之後的選取與標註都在這張凍結的畫面上進行。
- **GIF 編碼器**：自己實作，不依賴第三方套件。每格只編碼與上一格不同的矩形範圍；每格有自己的 255 色調色盤，顏色超過時用中位切割法（median cut）減色；LZW 壓縮也是自己寫的。
- **MP4**：透過 Media Foundation 的 Sink Writer 寫檔。COM 介面直接用函式指標呼叫，不另外宣告整套介面。
- **長截圖拼接**：每捲一次，等畫面連續兩次相同（捲動動畫結束）才擷取。每一行切成 16 段計算雜湊，至少 12 段相同才算同一行，用來找出這次捲動的距離；不跟著捲動的捲軸、側邊欄因此不會影響比對。頂端和底部固定不動的區塊在第一次捲動時偵測出來，只保留一份。
- **錄影暫停**：暫停時停止擷取並停住錄影時鐘，繼續後時間戳記接著往下算，所以影片裡不會有一段停住的畫面。
- **設定**：存在登錄檔 `HKCU\Software\ScreenCap`；開機時啟動寫在 `HKCU\...\CurrentVersion\Run`。
- **測試**：設定相關的測試改用另一個登錄機碼，不會動到使用者的設定。GIF 和 MP4 測試會把編碼結果解碼回來，逐像素比對；錄影測試會實際擷取螢幕，所以需要在已登入的桌面環境下執行。
